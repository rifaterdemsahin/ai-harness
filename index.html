📋 BMAD at the Core

The AI Harness is built around the BMAD framework — Build, Measure, Adjust, Deliver. It defines how agents coordinate, which compute handles what, how data flows from inputs through LLMs to outputs, and how external providers and tools plug in. Every node in the architecture diagram reflects a BMAD decision: what to build on, how to measure performance, where to adjust routing, and what value to deliver.
